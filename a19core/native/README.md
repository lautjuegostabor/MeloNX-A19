# A19Core native integration
Independent A19Core control plane and experimental prewarm/memory telemetry policy, using the pinned S2Arm native runtime, NVN/Metal libraries and Ryujinx HLE/Maxwell components as a compatibility backend. This is explicitly not a new independent emulation engine yet: the existing C++ reference interpreter is not a compatible replacement for the upstream native ABI (real guest pointers, TLS gates, relocations, service dispatch, platform lifecycle). It remains a reference, not in the retail path. The native frontend is our own, not the upstream Swift library. No game, key, signing identity or user resource is committed.
  
Device target iPhone18,3 / Apple GPU family 10; iOS 26+ SDK. Experimental adaptive prewarm is opt-in; when headroom is low for three samples or thermal reaches critical, do not launch additional speculative prewarm. No new pipeline limit asserted, no forced frame skipping, resolution, or guest speed, no eviction of active pipelines, no claim of higher FPS. Runtime writes actual game-frame aggregate diagnostics, sampling memory once per second, writing JSON at most every ten seconds.
  
Upstream Apache-2.0 and MIT notices preserved in build. Existing package format and same-team signature rules are retained. Build is not device validation. Do not install until link/pack success. See workflow a19core-integrated-host.yml.
