# A19Core Modular 1.3 — signing integration
Base a1954f146fffbb75c5070cbca591d168406f6047; ClearWidget build 23 source 5cb0913f0c7b7608041d3eaf9cfde22f1ad58895. Only host signing UI, lifecycle, native linker and permission metadata are adapted. Original BariStore GSA login, code/SMS interaction, route selection and profile renewal are reused. Encrypted CLEARRECOVERY1 session import supports an explicitly exported ClearWidget backup, using device-local Keychain separate from JIT and ClearWidget. No shared access group; no credentials in source or CI. The account's team and both installed app IDs, entitlements, certificates and UDID must match before installing either profile. Exact CMS readback required for both. No certificate revocation, new certificate issuance, binary reinstallation, bootstrap or full automatic recovery. LocalDevVPN needed. Existing version/bundle IDs, JIT helper, ROMs, core and performance patches preserved. Background renewal uses iOS BGProcessing plus a foreground/Shortcuts check; renewal starts only while the engine and game are inactive, but an active operation may overlap if a game is launched afterward. No game launch interception added. Tests and build must pass before distribution. Runtime and seven-day expiry are not yet verified; profile renewal cannot extend an expired signing certificate. The existing six-hour spacing applies only to unattended profile renewal, never to password authentication.
